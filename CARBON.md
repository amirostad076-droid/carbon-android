# CARBON Android

This is a branded build of the official Fluxer Flutter mobile client for the
CARBON instance at `fluxer.arashyn.ir`.

- Android application id: `ir.arashyn.carbon`
- Default API: `https://fluxer.arashyn.ir/api`
- Default gateway: `wss://fluxer.arashyn.ir/gateway`
- Push flavor: UnifiedPush (the supported self-hosted path)
- License: AGPL-3.0, matching upstream

The operator-provided CARBON artwork is used for the app icon, in-app brand
symbol, audio artwork, and Android launch screen.
